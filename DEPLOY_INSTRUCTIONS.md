# Инструкция по настройке автоматического деплоя

Чтобы ваш сайт автоматически обновлялся на сервере при каждом пуше в ветку `main` на GitHub, выполните следующие шаги.

## 1. Подготовка сервера

Зайдите на ваш сервер по SSH:
```bash
ssh root@your-server-ip
```

### Установите Docker и Docker Compose (если еще не установлены)
```bash
apt update
apt install -y docker.io docker-compose
```

### Создайте папку для проекта
```bash
mkdir -p /opt/aura-flora
chown -R $USER:$USER /opt/aura-flora
```

### Сгенерируйте SSH ключи (на вашем локальном компьютере, НЕ на сервере)
Это нужно для того, чтобы GitHub мог подключаться к вашему серверу.
```bash
ssh-keygen -t ed25519 -C "github-actions"
# Нажмите Enter, чтобы сохранить в стандартный файл (например, /Users/you/.ssh/id_ed25519)
# Не устанавливайте пароль (passphrase), просто нажмите Enter дважды.
```

### Добавьте публичный ключ на сервер
Скопируйте содержимое файла `.pub` (например, `id_ed25519.pub`), который вы только что создали.
На сервере выполните:
```bash
mkdir -p ~/.ssh
echo "ВСТАВЬТЕ_ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ_СЮДА" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
chmod 700 ~/.ssh
```

## 2. Настройка GitHub Secrets

Перейдите в ваш репозиторий на GitHub -> **Settings** -> **Secrets and variables** -> **Actions** -> **New repository secret**.

Добавьте следующие секреты:

| Имя секрета | Значение |
|-------------|----------|
| `SERVER_HOST` | IP-адрес вашего сервера (например, `123.45.67.89`) |
| `SERVER_USER` | Имя пользователя на сервере (обычно `root`) |
| `SSH_PRIVATE_KEY` | **Приватный** ключ, который вы сгенерировали (содержимое файла без расширения .pub). Скопируйте всё, включая `-----BEGIN...` и `-----END...`. |
| `ENV_FILE` | Содержимое вашего файла `.env`. См. пример ниже. |

### Пример содержимого для `ENV_FILE`:
Скопируйте это в значение секрета `ENV_FILE`, заменив значения на свои.

```env
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_secure_password
POSTGRES_DB=bloom_db

# Секреты приложения
JWT_SECRET=your_random_secret_string
GEMINI_API_KEY=your_google_gemini_api_key
TELEGRAM_BOT_TOKEN=your_telegram_bot_token

# Порт приложения (внутри контейнера)
PORT=8080
```

## 3. Запуск

Теперь, когда вы сделаете `git push origin main`, GitHub Actions автоматически:
1. Подключится к вашему серверу.
2. Скопирует новые файлы в `/opt/aura-flora`.
3. Пересоберет и перезапустит Docker контейнеры.

## Устранение неполадок

Если деплой не работает:
1. Зайдите во вкладку **Actions** в репозитории GitHub.
2. Нажмите на последний запуск.
3. Посмотрите логи ошибок.
4. Частая проблема: неправильные права доступа к папке на сервере или неверный SSH ключ.
